## Building Healthcare Tech That Actually Helps

Louise is this cool healthtech company working on women's reproductive health. As Senior Frontend Engineer, I got to build tech that helps OB/GYN doctors take better care of their patients with some pretty innovative digital tools.

## The Problem We Were Solving

Doctors needed a platform that could handle everything - managing patients, tracking treatments, dealing with billing, getting insights into their practice. And it all had to be accessible and work in multiple languages, which is no joke in healthcare.

## What I Built

### The Main Dashboard
Built this admin dashboard that completely changed how doctors run their practices:
- Full patient management from start to finish
- Real-time tracking of treatments and how patients are doing
- Billing that actually works and doesn't suck
- Analytics so doctors can see what's working and what isn't

### Design System That Makes Sense
Created a design system that became the foundation for everything:
- Components that actually look like the brand
- Accessibility built in from day one (WCAG 2.1 AA compliant)
- Reusable stuff like MultiSelect and Autocomplete that work properly
- Storybook setup so everyone knows how to use the components

### Making It Work Globally
Added full internationalization because healthcare isn't just in English:
- French and English support with seamless switching
- Localized healthcare terms that make sense in different regions
- Made doctor onboarding 60% faster in French-speaking areas
- Built it so adding new languages later would be easy

## The Tech Stack

Built everything with React and Next.js for performance, Tailwind for styling (because who has time for custom CSS), Storybook for component development, and Jest for testing. Used Next.js i18n for the multilingual stuff.

Made some key decisions early on:
- Everything component-based so we could reuse stuff
- Accessibility baked in with proper ARIA and keyboard navigation
- Code splitting and lazy loading so it loads fast
- TypeScript everywhere because debugging is pain enough already

## What I Learned

Working in healthcare really drives home how important user-centered design is, especially when what you build directly affects patient care. The accessibility requirements and multilingual stuff pushed me to think about inclusive design in ways I hadn't before.

It was cool seeing how good engineering can actually improve both how doctors work and how patients get treated. Healthcare tech is one of those areas where your code can genuinely make people's lives better.
